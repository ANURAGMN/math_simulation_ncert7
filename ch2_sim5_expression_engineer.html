Expression Engineer

Build expressions to hit target values!

Challenge
Using the given numbers with +, −, ×, ÷ and brackets, build an expression that equals the target. There are often multiple solutions — creativity with arithmetic properties helps!

How to Use This Simulation

What To Do
1Look at the target number at the top. Your goal is to build an expression that equals this number.
2Tap numbers, operations (+, −, ×, ÷), and brackets to build your expression.
3Tap the green = button to evaluate. If it matches the target, you win!
4In Four 4s mode, use exactly four 4s to make each number from 1 to 20.
Try This
Three 3s: (3+3)/3 = 2, 3+3−3 = 3, 3×3+3 = 12
Four 4s: (4+4)/(4+4) = 1, 4/4+4/4 = 2, (4+4+4)/4 = 3, 4+(4−4)×4 = 4
Using 2,3,5: 2−3+5 = 4, 3−(5−2) = 0, 5+3+2 = 10, 2×(3+5) = 16
Key Concept
The same numbers with different operations and bracket placement create very different values. This is the power of arithmetic expressions — brackets change everything!
