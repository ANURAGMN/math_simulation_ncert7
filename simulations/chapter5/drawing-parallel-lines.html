📏 Step 1: Draw the Base Line

Start by drawing a horizontal line using your ruler. This will be our reference line 'l' to which we want to draw a parallel line.

💡 Why This Works

Since both lines are perpendicular to the same transversal (the set square edge), the corresponding angles are equal (90°). When corresponding angles are equal, the lines must be parallel!

🎯 Understanding the Method

  • We use the property that corresponding angles are equal for parallel lines
  • The set square ensures both lines make the same angle with the ruler
  • By sliding the set square along the ruler, we maintain the same angle
  • This guarantees the new line is parallel to the original line
