📖 Key Concepts

  • Triangle Inequality: a + b > c for all side combinations
  • Angle Sum: ∠A + ∠B + ∠C = 180° always
  • SSS Construction: Use compass arcs from 2 vertices
  • Types: Equilateral, Isosceles, Scalene
  • If you know 2 angles, find the 3rd by subtracting from 180°
