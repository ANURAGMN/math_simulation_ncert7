Distributive Property

Multiple of a sum = Sum of multiples

The Property
Multiplying a number by a sum (or difference) inside brackets is the same as multiplying by each part separately and then adding (or subtracting).
a × (b + c) = a × b + a × c

How to Use This Simulation

What To Do
1In Area Model, drag sliders for a, b, c. The rectangle shows a×(b+c) split into two parts: a×b and a×c.
2In Mental Math, see how near-round numbers are decomposed for fast multiplication.
3Watch how both sides of the equation always equal the same value.
Try This
Area Model: Set a=4, b=5, c=3. The rectangle is 4 high and 8 (=5+3) wide. It splits into 4×5=20 (blue) and 4×3=12 (green). Total = 32 = 4×8.
Mental Math: Try 97×25. Think: 97 = 100−3. So 97×25 = 100×25 − 3×25 = 2500 − 75 = 2425. Much faster!
Key Concept
The distributive property lets you break hard multiplications into easy ones. Whenever a number is close to a round number (like 97 ≈ 100, or 104 ≈ 100), decompose it and use the property!
