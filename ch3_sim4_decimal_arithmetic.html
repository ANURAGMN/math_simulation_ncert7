Decimal Mission Builder

Hit the target under move constraints

Learning Strategy
You win by combining decimal additions and subtractions to land exactly on the target. Strong strategy: mentally align decimal points and combine tenths/hundredths before tapping cards.

How to Play

1. In Mission Mode, each level has a start value, a target, and a move limit.
2. Tap operation cards like +5.3 or -1.2. Each card can be used once.
3. Reach the exact target before moves run out. Some missions require subtraction cards.
4. Use Show Hint if stuck, then retry to improve your streak.
5. Re-run missions with fewer moves and no hints to improve strategy.
